A tecnologia também deve enxergar as diferenças

Este projeto apresenta atividades desenvolvidas durante o segundo trimestre envolvendo Física, Programação e Robótica.

O objetivo é demonstrar como diferentes tecnologias podem promover maior autonomia, inclusão e acessibilidade para pessoas com baixa visão ou cegueira.

02

Programação e Inclusão Digital

Na Programação, diferentes conhecimentos são integrados para desenvolver soluções digitais acessíveis.

Desenvolvimento do site

Os estudantes aplicam conceitos de HTML, CSS, JavaScript, design de interfaces e gestão de projetos.

Durante o desenvolvimento são consideradas necessidades específicas de pessoas com baixa visão ou cegueira.

  • HTML semântico
  • Navegação utilizando teclado
  • Compatibilidade com leitores de tela
  • Contraste adequado entre cores
  • Textos alternativos em imagens
  • Tamanho de fonte ajustável
  • Links facilmente identificáveis

Você sabia?

Pessoas que utilizam leitores de tela normalmente navegam pelo site usando títulos, links, botões, regiões e outros elementos semânticos.

Por isso, utilizar corretamente as tags HTML ajuda diretamente na acessibilidade.

Teste de acessibilidade

Tente navegar neste site sem utilizar o mouse.

Pressione a tecla Tab para avançar pelos elementos interativos e Shift + Tab para retornar.

Código dos Projetos

Os códigos utilizados nos protótipos também podem ser compartilhados neste espaço. 

// Exemplo de leitura de sensor


const int sensor = 2;
const int buzzer = 8;


void setup() {


pinMode(sensor, INPUT);
pinMode(buzzer, OUTPUT);


}


void loop() {


int obstaculo = digitalRead(sensor);


if (obstaculo == LOW) {


digitalWrite(buzzer, HIGH);


} else {


digitalWrite(buzzer, LOW);


}


}

Sobre o Projeto

Este projeto interdisciplinar tem como objetivo integrar os conhecimentos desenvolvidos nos componentes curriculares de Física, Programação e Robótica.

A proposta busca estimular os estudantes a compreenderem que a tecnologia pode contribuir diretamente para melhorar a qualidade de vida e proporcionar maior autonomia às pessoas.

“A tecnologia só é verdadeiramente inovadora quando também pode ser utilizada por todos.”
